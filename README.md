# Автотесты для интернет-магазина Intershop (Skillbox Final Work)

Проект содержит набор автоматизированных UI-тестов для сайта `intershop5.skillbox.ru`, написанных на Java.

## 🛠 Стек технологий:
*   **Java 21**
*   **Selenium WebDriver 4**
*   **JUnit 4**
*   **Maven** (сборка проекта)
*   **WebDriverManager** (автоматическая загрузка драйверов)

## 📋 Что покрыто тестами (5 страниц):
1.  **Главная страница**: проверка отображения ключевых элементов, работа поиска, наличие блока распродажи.
2.  **Каталог**: проверка сетки товаров, пагинации, переход в карточку товара, хлебные крошки, переход в подкатегорию.
3.  **Корзина**: добавление товара, применение купона (`sert500`), удаление товара, проверка итоговой суммы.
4.  **Авторизация и Регистрация**: успешная регистрация, вход с верными/неверными данными, валидация пустых полей.
5.  **Оформление заказа**: успешное оформление заказа с заполнением всех полей, валидация пустых полей.

## 🏗 Архитектура проекта:
В проекте используется базовый класс `BaseTest`, который содержит настройку драйвера (через `WebDriverManager`) и закрытие браузера после теста. Все тестовые классы наследуются от него, что делает код чистым и избавляет от дублирования.

**Запуск тестов:** `mvn test` (или через IDEA).
